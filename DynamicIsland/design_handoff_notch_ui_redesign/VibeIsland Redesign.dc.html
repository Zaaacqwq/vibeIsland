VibeIsland — UI / UX Redesign

One island.
Every surface, one system.

The notch's tabs used to read like seven different apps. This redesign gives every surface — the collapsed pill, home, media, agents, stats, clipboard, color — a single ink-and-hairline language: Geist for voice, Geist Mono for the technical layer, one restrained accent, and data that never shouts louder than the content.
